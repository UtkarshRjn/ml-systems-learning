| [`cuda_cpp_tutorial.html`](cuda_cpp_tutorial.html) | Complete CUDA C++ background-knowledge tutorial built from a survey of all 84 problems on [tensara.org](https://tensara.org/problems). Organized around 6 reusable patterns (element-wise, stencil, reduction, scan, matmul tile, online softmax) plus specialty topics: tensor cores (WMMA / mma.sync / wgmma), MXFP4 / MXFP8 / NVFP4 quantized GEMM, GPU graph algorithms (Floyd-Warshall, Bellman-Ford, Prim), finite-field arithmetic, FlashAttention. 1D convolution is the worked end-to-end example. |
